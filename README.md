# Luo's Theory Lab

Research group website for **Luo's Theory Lab** (Nanjing University of Science and Technology), built with [Astro](https://astro.build).

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

Site URL: <https://kluonj.github.io/>

Content lives in `src/content/` (people, publications, research, teaching, posts). Static assets (photos, PDFs, bib files) are in `public/`.
